O portal do Wi-Fi de visitantes guarda os cadastros e as senhas num banco MySQL. A Gestão TI lê esse banco para listar os visitantes e grava lá a senha nova quando a TI troca. O visitante entra com a senha nova na hora.

Login (username) e senha (value) do RADIUS. A senha fica em código (ex.: MD5), conforme a coluna attribute; a Gestão TI grava no mesmo formato.

Recomendado: criar um usuário do MySQL só para a Gestão TI

Em vez do root, entre no servidor do banco (SSH/PuTTY), abra o MySQL com mysql -u root -p (ou sudo mysql) e rode os comandos abaixo, trocando a senha. Depois use gestaoti e essa senha nos campos acima, com “Conectar por SSH” marcado.

CREATE USER 'gestaoti'@'localhost' IDENTIFIED BY 'uma-senha-forte';
CREATE USER 'gestaoti'@'127.0.0.1' IDENTIFIED BY 'uma-senha-forte';
GRANT SELECT, UPDATE ON radio.reg_users TO 'gestaoti'@'localhost', 'gestaoti'@'127.0.0.1';
GRANT SELECT, UPDATE ON radio.radcheck  TO 'gestaoti'@'localhost', 'gestaoti'@'127.0.0.1';
FLUSH PRIVILEGES;

Com isso a Gestão TI só consegue ler e alterar essas duas tabelas. Por que não o root: em muitos servidores o root do MySQL só entra pelo terminal do próprio servidor e recusa programas.
